# SQL 문법 정리

## 최댓값 구하기

### 사용한 SQL

```sql
SELECT DATETIME AS '시간'
FROM ANIMAL_INS
WHERE DATETIME = (
    SELECT MAX(DATETIME)
    FROM ANIMAL_INS
);
```

### 문제 이해하기

이 문제는 동물 보호소에 들어온 동물 정보가 저장된 `ANIMAL_INS` 테이블에서 가장 최근에 들어온 동물의 보호 시작 시간을 조회하는 문제입니다.

보호 시작 시간은 `DATETIME` 컬럼에 저장되어 있습니다.

가장 최근 시간은 날짜와 시간 값 중에서 가장 큰 값이므로 `MAX(DATETIME)`을 사용해 구할 수 있습니다.

### 핵심 문법

#### 1. SELECT

```sql
SELECT DATETIME AS '시간'
```

`SELECT`는 조회할 컬럼을 선택할 때 사용합니다.

이 문제에서는 가장 최근 보호 시작 시간을 출력해야 하므로 `DATETIME` 컬럼을 조회합니다.

문제에서 출력 컬럼명을 `시간`으로 요구하므로 `AS '시간'`을 사용해 별칭을 지정합니다.

#### 2. FROM

```sql
FROM ANIMAL_INS
```

`FROM`은 데이터를 조회할 테이블을 지정할 때 사용합니다.

동물 보호소에 들어온 동물 정보는 `ANIMAL_INS` 테이블에 저장되어 있으므로 해당 테이블에서 데이터를 조회합니다.

#### 3. MAX()

```sql
SELECT MAX(DATETIME)
FROM ANIMAL_INS
```

`MAX()`는 특정 컬럼에서 가장 큰 값을 구하는 집계 함수입니다.

날짜와 시간 데이터에서도 `MAX()`를 사용할 수 있습니다. 날짜가 늦을수록 더 큰 값으로 판단되기 때문에 `MAX(DATETIME)`은 가장 최근 시간을 의미합니다.

예를 들어 `DATETIME` 값이 다음과 같다면

| DATETIME |
| --- |
| 2017-10-11 12:00:00 |
| 2018-02-03 09:30:00 |
| 2019-01-20 15:10:00 |

`MAX(DATETIME)`의 결과는 가장 늦은 시간인 `2019-01-20 15:10:00`입니다.

#### 4. 서브쿼리

```sql
WHERE DATETIME = (
    SELECT MAX(DATETIME)
    FROM ANIMAL_INS
)
```

서브쿼리는 SQL문 안에 포함된 또 다른 SQL문입니다.

이 풀이에서는 먼저 서브쿼리로 `ANIMAL_INS` 테이블에서 가장 큰 `DATETIME` 값을 구합니다.

그다음 바깥 쿼리에서 `DATETIME`이 그 값과 같은 행을 찾아 출력합니다.

### 실행 흐름

1. `ANIMAL_INS` 테이블에서 모든 `DATETIME` 값을 확인합니다.
2. 서브쿼리에서 `MAX(DATETIME)`으로 가장 최근 시간을 구합니다.
3. 바깥 쿼리의 `WHERE` 조건에서 `DATETIME`이 가장 최근 시간과 같은 행을 찾습니다.
4. 해당 행의 `DATETIME` 값을 `시간`이라는 컬럼명으로 출력합니다.

### 최종 정리

이 문제의 핵심은 날짜와 시간 컬럼에서도 `MAX()`를 사용해 가장 최근 값을 구할 수 있다는 점입니다.

`MAX(DATETIME)`으로 가장 최근 보호 시작 시간을 찾고, 그 값과 같은 `DATETIME`을 가진 행을 조회하면 됩니다.

```sql
SELECT DATETIME AS '시간'
FROM ANIMAL_INS
WHERE DATETIME = (
    SELECT MAX(DATETIME)
    FROM ANIMAL_INS
);
```
